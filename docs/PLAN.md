## Что будет видно в конце каждого этапа

- Этап 1: репозиторий на GitHub, README и план.
- Этап 2: архитектурный документ, описание API и баз данных.
- Этап 3: `docker compose up --build` поднимает пустые сервисы, CI зелёный, первый тест проходит.
- Этап 4: прошлые сессии загружаются из OpenF1 и сохраняются в Telemetry. Позиции из ESPN доходят до Live, изменение позиции вызывает уведомление для подписанного пользователя. Есть отчёт нагрузочного теста.
- Этап 5: каталог, импорт, результаты сессий и live-сценарий доступны через браузер.
- Этап 6: проект запускается по README в чистой папке, результаты тестов приложены, демонстрация подготовлена.

## Риски

- ESPN может быть недоступен или изменить формат данных.
- У OpenF1 есть лимиты запросов и ограничения доступа во время live-сессий.
