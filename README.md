# F1 Monitor

Веб-приложение для наблюдения за гонками Формулы 1.

Пока идёт гонка, пользователь видит на экране текущую таблицу с позициями, время круга пилотов, разрывы между пилотами и другие данные. Если происходит что-то важное, например пилот заехал на пит-стоп, приложение присылает уведомление. Правила для уведомлений настраивает сам пользователь.

Когда гонка закончилась, данные не пропадают. Пользователь выбирает гонку из списка и смотрит всё, что по ней сохранилось.

## Что примерно можно будет делать в приложении

- Смотреть ход гонки в реальном времени: позиции, круги, пит-стопы, разрывы, погоду, флаги.
- Создавать правила уведомлений. Например сообщить, если разрыв между пилотами меньше 1 секунды.
- Добавлять пилотов в избранное и получать уведомления только по ним.
- Выбирать прошедшую гонку из списка и смотреть её данные.
- Сравнивать двух пилотов.
- Регистрироваться и входить в аккаунт. Каждый пользователь видит и меняет только свои подписки на уведомления и избранных пилотов.

## Из чего примерно будет состоять проект

| Сервис | Что делает | База данных |
|---|---|---|
| Gateway.Api | Единая точка входа: все запросы от сайта идут через него | нет |
| Auth.Api | Регистрация, вход, выдача JWT-токена | PostgreSQL (authdb) |
| Telemetry.Api | Хранит данные гонок, показывает список гонок и сравнивает пилотов | PostgreSQL (telemetrydb) |
| Alerts.Api | Хранит правила, подписки и избранных пилотов, проверяет правила и создаёт уведомления | PostgreSQL (alertsdb) |
| Live.Api | Отправляет данные на сайт в реальном времени (SignalR), хранит текущее состояние гонки | Redis |
| f1-collector | Программа на Python, которая получает данные о гонке и передаёт их остальным сервисам через RabbitMQ | нет |
| Frontend | Сайт на Vue 3 | нет |

Сервисы общаются через очередь сообщений RabbitMQ.

## Технологии

- Сервисы: ASP.NET Core, Entity Framework Core, YARP, SignalR
- Базы данных: PostgreSQL, Redis
- Очередь сообщений: RabbitMQ
- Сбор данных: Python (библиотека FastF1)
- Веб интерфейс: Vue 3
- Запуск: Docker Compose
- Логирование: Serilog
- Тесты: xUnit
- CI/CD: GitHub Actions
